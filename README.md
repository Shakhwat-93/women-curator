# WOMEN CURATOR — Luxury Fashion Direct Order Landing Page

A production-ready, ultra-premium contemporary fashion e-commerce landing page & direct sales funnel for **WOMEN CURATOR**. Designed with high-fashion editorial aesthetics, signature organic background geometry, responsive hero auto-slider, and direct Cash on Delivery ordering.

---

## ✨ Features

- **Signature Visual Design System**:
  - Warm cream canvas (`#FAF5EE`), signature coral accent (`#DE4F3C`), soft blush pink (`#F4A999`), and deep charcoal.
  - Parametric `OrganicBackground` generator creating layered fluid blobs, delicate white arcs, and dotted matrices.
  - Editorial typography hierarchy (`DM Serif Display`, `Playfair Display`, `Alex Brush`, `Plus Jakarta Sans`, and `JetBrains Mono` for tech/shipping details).

- **High-Converting Direct Sales Funnel**:
  - **Campaign Hero Auto-Slider**: 4-second cross-fade carousel across high-resolution campaign banners.
  - **4-Product Grid (1:1 Reference Card Fidelity)**: Interactive color swatches, badges, strikethrough price formatting, and 1-click selection.
  - **In-Page Direct Order Form**: Real-time garment, color, size, and quantity picker + customer destination form + automated delivery fee calculation (Inside Dhaka ৳80 / Outside Dhaka ৳150) + instant Cash on Delivery order placement.
  - **Order Confirmation**: Celebratory confetti animation with receipt details and order tracking ID (`WC-XXXXXX`).
  - **Mobile Sticky Order Bar**: 1-tap quick checkout button for smartphones.

- **Modern Architecture**:
  - React 19 + TypeScript + Vite + Tailwind CSS + Framer Motion + Lucide React.
  - Decoupled Supabase repository layer with resilient offline fallback.
  - Vercel deployment ready.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

---

## 🌐 Deploying to Vercel

1. Push this repository to GitHub:
   ```bash
   git remote add origin git@github.com:Shakhwat-93/women-curator.git
   git branch -M main
   git push -u origin main
   ```
2. Go to [Vercel Dashboard](https://vercel.com/new).
3. Import the `women-curator` repository.
4. Click **Deploy** (Vercel automatically detects Vite and `dist` output).
